# 主炮彈種與傷害

#17 在既有單發砲膛循環中加入高爆與穿甲。只有裝填手的實體按鍵 1／2 能選彈；離散指令 5／6 經可靠動作通道送到房主，與按住 R 的裝填輸入分開。開裝時將選擇存入 chamberShell；放開 R、中途按選彈鍵、裝好等待都不能改變該發或重設進度。發射將彈種複製到飛行彈後釋放鎖定，退殼照常完成才可裝下一發。

高爆初始直接傷害100，爆炸半徑5公尺、鄰近目標傷害60；穿甲直接傷害180，無範圍傷害。這是可調遊戲數值，沒有史實擊穿公式。兩個前方練習靶各200HP，正常裝填、射擊即可受損及擊毀；公開HP讀值與實際模型的受損顏色／殘骸同步，不讀取測試專用隱藏戰況。砲手觀察點移到炮盾前緣，避免己方炮塔頂部擋住正前靶。

爆炸受傷清單只含敵對靶標；己方坦克不在主炮碰撞／受傷清單。tank.hp提供100HP共用基線並在三個工作站顯示，近距離爆炸可傷靶而不扣己方血量。敵方攻擊、扣血與失敗屬#21，待該票接入後須以敵方確實能傷己方的情境重跑友軍自傷回歸；本票不把尚未存在的敵方傷害宣稱已驗證。

高爆、穿甲、煙霧的供應模型皆無限，沒有彈藥數量、卸彈或補給；本階段只有高爆與穿甲可選，煙霧保留型別與供應說明，實際選擇及遮蔽效果由#22加入。初始場景與車內CSS機構仍由#25/#26完成最終偏寫實美術。
