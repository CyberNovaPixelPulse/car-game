# 主炮彈種與傷害

#17 在既有單發砲膛循環中加入高爆與穿甲。只有裝填手的實體按鍵 1／2 能選彈；離散指令 5／6 經可靠動作通道送到房主，與按住 R 的裝填輸入分開。開裝時將選擇存入 chamberShell；放開 R、中途按選彈鍵、裝好等待都不能改變該發或重設進度。發射將彈種複製到飛行彈後釋放鎖定，退殼照常完成才可裝下一發。

高爆初始直接傷害100，爆炸半徑5公尺、鄰近目標傷害60；穿甲直接傷害180，無範圍傷害。這是可調遊戲數值，沒有史實擊穿公式。目標為三波實際四號與虎式敵車；公開已知 HP 只在隊伍觀測時刷新，實際模型與殘骸讀同一權威戰況，不提供測試專用隱藏讀值。砲手觀察點位於炮盾前緣，避免己方炮塔頂部擋住正前目標。

爆炸受傷清單只含敵車；己方坦克不在主炮碰撞／受傷清單。`tank.hp` 提供100HP共用基線並在三個工作站顯示，近距離爆炸可傷敵車而不扣己方血量。敵彈可真正傷害己方並造成 HP0 失敗；友軍近距離自傷、實際敵彈與 HP0 分別由正常戰鬥流程驗證。

高爆、穿甲、煙霧的供應模型皆無限，沒有彈藥數量、卸彈或補給；三彈種均可由 1／2／3 正常選擇。煙霧的真實遮蔽、AI 記憶與隊伍舊情報見 [煙幕](tank-smoke.md)；三工作切換保留同發彈種、裝填、卡彈及冷卻。

與#18/#19整合後，選彈沿用loaderCanWork：蹲下與暈眩中不能選下一發，既有鎖定彈不會被清除。卡彈只暫停同一發的裝填，不換彈、不重擲或清除進度；成功排除後仍射出開裝時的彈種。射出後且尚未蹲下／暈眩時可先選下一種，但退殼截止前不能提前開裝。

離散動作會先提交目前held輸入：房主先更新核心輸入，客端先在同一可靠有序連線送input、再送action，兩者沿用共用遞增序號。TankCore在收到裝填手輸入時即同步蹲姿，仍以同一模擬時鐘檢查暈眩。這讓放開C立刻按2按原順序生效，不必等下一個50ms輸入週期；按住C的動作仍正確封鎖，也不合併或遺失離散連點。
