# 坦克 3D 接入

#14 在 tank.html 使用 TankCore＋GameRuntime，沿用 Session('tank') 的房主權威、輸入與快照傳輸。舊賽車仍使用原 Engine，不在本片移除。

TankCore 保存版本化坦克戰況（模擬時間、車身位置／朝向、速度、轉速與受阻狀態）。input 以房間成員職位驗證，只有 driver 的 held bitmask 生效。現階段 W/S/A/D 佔用 bit 1/2/4/8；未來主炮連點、選彈、切模式等離散指令需要獨立表示，不能把多次實體按下 OR 成同一個位元而遺失點擊。

只有房主推進核心，其他客端還原快照。TankScene 消費權威狀態，每個畫面更新繪製主炮方向的 3D 視野；只為砲手建立 WebGL canvas，駕駛沒有外部畫面或隱藏座標 DOM。裝填手保留車內工作站，武器及機槍待後續票接入。

固定障礙描述同時用於渲染與碰撞；初始車體、場景與材質為功能接入，最終二戰寫實外觀仍由 #25/#26 完成。主炮目前隨車身方向，#15 增加獨立 yaw/pitch/慣性後，需同步調整 camera 方向與朝向儀表。車體 heading 是砲手真實可見的指路儀表；不可把世界座標放進駕駛 UI 方便測試。

stationRole 快取避免房間訊息重複建立 renderer；離開時 menu 會釋放 renderer 與輸入。後續同房再玩必須在回 lobby 時結束舊工作站／清除此快取，再建立新職位場景。後續暫停須凍結核心時間，另用現實時間計重連期限。

tests/tank-helpers 提供以真實表單、按鍵建立「裝填手房主＋非房主駕駛＋砲手」的共駕情境。測試讀取可見速度／動態／受阻與砲手朝向，並以真實渲染 canvas 截圖比較移動前後場景；沒有直接注入位置或讀取內部戰況。
