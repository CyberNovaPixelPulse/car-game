# 坦克音效

我方坦克以 M4／M4A1 雪曼為聲音藍本（Continental R975 九缸星型引擎、液壓砲塔、75 mm M3 主炮、半自動立楔式閂體）。引擎聲參考 militarymuseum.at 的「WWII Sherman tank engine startup」影片：只在瀏覽器裡量測頻譜特徵（怠速曲軸約 18.5 Hz、主峰約 4.5 倍曲軸頻率的 73～97 Hz、音色中心約 1 kHz、明顯的不規則頓挫），沒有複製影片音訊。所有聲音都由 WebAudio 即時合成，不使用外部錄音或付費素材。音效只讀取權威快照，不改變任何規則、計時或判定。

## 排氣回火

星型引擎油門一收（轉速比剛才的高點掉 380 rpm 以上）會在排氣管爆出 1～3 聲「啪啪」，怠速時偶爾也會冒一聲。回火聲從車外傳來，在車內會被裝甲悶住。

## 戰場音效

| 聲音         | 觸發                          | 做法                                                                                                                        |
| ------------ | ----------------------------- | --------------------------------------------------------------------------------------------------------------------------- |

| 砲彈擦過     | 敵彈飛過我車 7 m 內但沒命中   | 超音速爆裂加上撕裂空氣聲，從彈道那一側傳來。                                                                                |

| 我方砲彈命中 | 新的 `impacts`                | 高爆彈是遠處爆炸加泥土落下；穿甲彈是硬撞擊；煙霧彈是開殼聲加持續嘶聲。同樣依位置延遲與定位。                                |

| 風聲         | 一直存在                      | 低頻風聲帶兩層慢速陣風起伏；車內幾乎聽不到，艙外明顯。                                                                      |
| 遠方砲擊     | 每 9～27 秒隨機               | 戰場外的砲兵齊射，只剩低頻滾雷，1～3 發一組；戰鬥結束後停止。                                                               |

聲音的左右方向以聽者的視線為準：駕駛看車頭、砲手和車內裝填手看主炮方向、艙外裝填手看機槍方向。在背後的聲音會稍微悶一點。

## 聽感與位置

- 駕駛、砲手和在車內工作的裝填手都在封閉車體內，車外傳進來的聲音（引擎、履帶、戰場）經低通濾波（約 2.6 kHz），高頻被裝甲悶住。
- 砲塔裡發生的聲音（閂體、推彈、彈殼、被擊中的裝甲迴響）不經濾波，金屬與黃銅的清脆聲聽得清楚。
- 裝填手切到車頂機槍時頭在艙外，濾波打開，主炮會帶出田野與建物的回音。
- 主炮是最大聲的事件；引擎怠速約 −18 dBFS。最後一級是不會超過滿刻度的軟削波，而非 WebAudio 壓縮器（壓縮器的自動補償增益會把引擎抬高）。
- 退殼等危險警示嗶聲響起時，坦克音效會短暫降低約 8 dB，確保警示聽得見。被擊中時不降低，讓裝甲撞擊聲保持震撼。

## 主炮錄音

我方主炮以 `public/audio/cannon-sfxengine.mp3`（SFX Engine 生成的坦克開砲錄音）為主，下面疊一層低通 240 Hz 的合成砲口壓力波，再接原本的閂體後座、復進與車內零件震動。敵方開砲同時播放這段錄音（依距離延遲、低通、壓低音高）與原本的遠方合成砲聲。錄音沒有載入時自動退回全合成。設定在 `public/audio/manifest.json` 的 `samples.cannon`，詳見 `public/audio/README.md`。

## 裝填手語音

預設使用瀏覽器語音合成，優先選美國英語男聲（有 Natural／Online 版本時優先，例如 Edge 的 Guy、Andrew、Christopher），語速 1.35、音高 1.3，聽起來較急、較激動。沒有美式英語聲音時改用任何英語聲音。語音合成無法真正表達情緒，想要真人吶喊的效果請用錄音。

想換成真人錄音，見 [public/audio/README.md](../public/audio/README.md)：把檔名填進 `public/audio/manifest.json` 即可，錄音會自動套用通話器濾波。

## 開關

每位乘員的工作站右上都有「音效」開關，各自只影響自己的電腦。關閉時同時靜音坦克音效、裝填手機械聲、危險預警與命中聲，並停止語音；所有警示仍有可見提示。

## 試聽與驗證

`npx tsx tools/render-audio-preview.ts [輸出資料夾]` 會把所有單次音效（主炮、閂體、彈殼、履帶板等）輸出成 WAV，預設放在 `output/audio-preview/`，同時檢查沒有 NaN 或爆音。引擎、履帶與砲塔等連續聲音需在遊戲中聆聽。

實作檔案：

- `web/tank-audio-synth.ts`：不依賴瀏覽器的物理式合成（金屬與黃銅的非諧波共振、濾波噪音）。
- `web/tank-vehicle-audio.ts`：WebAudio 即時音效圖、快照邊緣觸發、語音通知。
- `web/tank-battle-audio.ts`：戰場事件（敵砲、命中、擦過、彈著、殉爆、機槍、維修、遠方砲擊）的觸發與定位。
- `web/tank-mechanical-audio.ts`：裝填手專屬的卡彈、過熱、切換工作與校準提示。

自動測試的 Chromium 預設靜音，測試通過不代表人工聽過。
