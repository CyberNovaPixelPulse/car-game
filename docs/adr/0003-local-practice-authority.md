# 單人練習共用權威規則，以合法職位操作接入 AI

#45 新增單人練習，擴充 ADR 0002 原本只有私人三人房間的啟動條件。本機練習直接推進同一 TankCore 與共同遊戲時鐘，AI 與真人都經職位驗證的 held input／離散 action 工作；不另造簡化傷害核心，也不建立假 Session 或依賴 PeerServer。

正式多人保留既有三席協定與房主權威。單敵輪次及 AI 控制偏好屬本機練習，不改寫多人快照版本。暫停先完成過去時間，再凍結核心與安全清鍵；換職準備畫面期間保持凍結，素材成功後才交換職位，失敗可回原職位重試。AI 砲手採自己的 16:9 主炮觀測投影，與真人 canvas 分開，使用既有視線／煙幕／掩體判定；AI 駕駛共用固定掩體的繞行查詢。這避免私人狀態注入與真人畫面尺寸影響 AI 視力，代價是單人模式仍須維護與正式規則相同的完整工作生命週期。
