# 本機場景畫質

戰鬥右上「畫質」提供低／中／高，預設中。選擇只影響這個分頁的 3D 繪圖緩衝，所有職位、裝填手車內／機槍及維修共用相同設定。偏好保留到本分頁的後續回房、換職及重玩；重新載入頁面回到中畫質。

每個視野的總像素預算為低 921,600（1280×720）、中 2,073,600（1920×1080）、高 3,686,400（2560×1440）。這是 16:9 等效像素總量；其他比例保持實際 canvas 比例，不強行改成 16:9。另有每個 CSS 像素最多 2×2 個繪圖像素的上限，所以很小的視窗不會用滿預算。在 1280×720 視窗三檔分別得到 1280×720、1920×1080、2560×1440 的真實 buffer。這些上限不是硬體效能或 FPS 保證。

繪圖尺寸由共用的 `tank-scene-quality` 決定。外景與車內都在實際尺寸改變或畫質改變時更新 buffer；相同 CSS 尺寸也會套用新設定。準備中的視野、已準備視野、隱藏車內及暫時移除的機槍 canvas 都保留各自尺寸並更新設定；切換模式後沿用原有 renderer、資產及 shader。畫質切換只重配 framebuffer 並標記重畫，不重建房間、工作站或權威核心，也不重新載入模型或編譯另一套材質。

DOM 的 HUD、按鈕、工作介面與 SVG 導航按實際頁面解析度顯示，與 3D 場景預算分開。CSS 尺寸、相機比例／FOV、角色觀察權限、偵察與遊戲規則不由畫質改變。載入失敗與軟體渲染仍使用既有程序資產降級；低畫質本身不切換資產層級、陰影或貼圖來源。
