# 戰鬥頁面與 HUD

#30／#33 將戰鬥的手冊外框改為鋪滿頁面的真實 3D 視野。入口與大廳維持原有雙色手冊；只有戰鬥採深色半透明底襯與亮色文字。文字、按鈕與進度條使用 DOM，與場景的繪圖解析度分開。

左上顯示職位、共用 HP、波次、速度、車況與車頭／主炮方向。右上 `.battle-utility` 保留離房、音效及後續本機顯示設定的操作列；操作增加時先在自身欄位換行，敵情、煙幕與飛行彈資訊在其下方順排，與中央警示維持分欄。右下為當前工作與彈藥、裝填／機槍熱度、冷卻及鍵盤提示。危險與缺員暫停放在上方中央，正常主炮／機槍準星周圍保留觀察區。警示同時交代中文狀態和數字，不能只依賴顏色。

左下的 `.battle-navigation` 由 #36 接上共用導航元件，位置由所有職位共用；預設方形地圖寬 192px，標題／圖例向上增高，保留底部安全距離。高度不超過 800px 的駕駛畫面使用 160px 地圖及緊湊圖例，讓整個受限觀察窗保持暢通，仍顯示完整場地。導航規則見 [共用戰場導航](tank-navigation.md)。裝填手的裝填按鍵提示使用 `.loading-help`，只在裝填模式顯示。車內卡彈與維修工作位於中央；新增校準沿用維修區，不擠進角落讀數。裝填手三種工作切換仍重用原有真實場景與權威狀態。

戰鬥容器 `.battle-station` 同時包含實際視野、HUD、小地圖、工作面、暫停、結果與返回控制。#34 讓每名乘員自行按右上「進入全螢幕」請求完整容器；房主開戰不會替其他玩家請求。按 Esc 或「退出全螢幕」返回鋪滿頁面模式，房間及工作狀態保留。狀態按瀏覽器公開的 `fullscreenElement`／`fullscreenchange` 更新；不可用或失敗時顯示本機提示。可信 Esc 事件到達頁面時也只替目前工作站呼叫標準退出 API，不攔截瀏覽器原生退出控制，不鎖定鍵盤。API 行為參考 [WHATWG Fullscreen Standard](https://fullscreen.spec.whatwg.org/)。

滑鼠點擊全螢幕／音效後將焦點交還戰場，可立即使用方向鍵、R 等操作；鍵盤啟用則保留原生按鈕焦點。焦點在按鈕、表單或選單時，全域遊戲鍵不代替原生 Space／Enter／Tab／方向鍵；實際 keyup 仍安全釋放先前按住的輸入。

頁面尺寸改變只重新安排呈現，不重建房間或工作狀態。結算時中央維修／卡彈工作面隱藏，避免透過結果層露出文字。結算與缺員暫停時，離房和必要返回動作仍可見；回到大廳／主選單恢復手冊排版並釋放全螢幕擁有權、事件與過期請求，在轉場時回到頁首。

駕駛畫面周邊是相機前的實體裝甲，仍保留真正水平 60°、垂直 16°的開口及厚度。移除 HTML 外框不會擴大觀察範圍，也不會把裝甲移除。現有坦克、地景與車內資產維持不變。

驗證接點沿用正常三人瀏覽器／鍵盤、真實 PeerJS／WebRTC 與可見 HUD；桌機矩陣為 1280×720、1440×1050，窄入口 390px。測試與截圖證據的具體來源和限制記於各票報告及最終整合驗證，不以文件描述代替實際驗證。

右上原生「畫質」選單提供低／中／高，預設中；只改本分頁的 3D buffer，HUD、工作與導航保持原有 DOM／SVG 清晰度。選單與按鈕同在操作列內換行，亮字有深色底襯；選單取得焦點後方向鍵屬於原生選擇，不同時轉炮。像素上限及資源生命週期見 [本機場景畫質](tank-quality.md)。
