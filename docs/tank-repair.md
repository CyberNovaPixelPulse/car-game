# 裝填手車內維修與校準

Tab 依序循環裝填、機槍、維修，再回到裝填。維修重用準備階段載入、編譯及首畫完成的封閉車內 renderer，中央面板顯示工作條件與圓形校準。沒有外部戰場視野；原有退殼預警、C 蹲下、固定五秒暈眩與武器狀態仍可見。

按住 R 時，房主在每次完整 elapsed 的物理子步先處理敵彈傷害與車身移動，再判斷維修。存活、未蹲下／暈眩、速度與轉速絕對值均不超過 0.01，且受擊與校準失敗等待已結束，才每秒回復 2 HP，最高 100。沒有材料限制；滿血暫停基本回血及下一次校準的工作累積。HP 歸零在同一步立即失敗，不能由基本維修或校準獎勵復活。HUD 的小數血量顯示到一位，規則保留連續精度。

每次敵彈實際扣血都令禁修期限至少延至該次命中加三秒；新的命中重新計時。放開 R、移動／轉向、蹲下／暈眩或切換工作都停止回血。三模式切換保留同一發彈種、進度、卡彈、退殼、機槍熱度與冷卻；空白鍵由房主依目前模式解讀，不能同時停維修指針、排卡彈及發射機槍。

## 圓形維修校準

每累積 3～6 秒實際有效維修，出現一次校準。一般目標區為 90°，其中較亮、較細的 21.6° 區域為完美區；每次開始時目標位置重新抽取。指針從上方順時針繞行一圈，完整一圈為兩秒遊戲時間。可見角度文字與圓形圖使用相同權威快照，CSS 不自行跑另一套時鐘。

繼續按住 R 可同時取得每秒 2 HP 基本回血。裝填手按空白鍵時，房主依收到動作當下的指針判定：一般區額外 +1 HP，完美區該次總額外 +3 HP，不將一般獎勵再相加。所有回血仍以 100 為上限。若基本回血先達滿血，已經開始的判定仍可完成，獎勵會受上限截斷。

按錯、兩秒內漏按、放開 R、切換工作、移動／轉向、蹲下、敵彈受傷或退殼暈眩都令未完成校準失敗一次。失敗保留已修復 HP，從失敗當下停修兩秒；受擊三秒與失敗兩秒重疊時取較晚結束的期限，不累加。重複空白鍵、同刻多種中斷或切換工作都不重結算、不清除等待、不重新抽有利目標。下一次校準必須重新累積正常有效工作。

中央面板顯示停車、蹲下／暈眩、受擊等待或校準失敗等待；三位乘員都有同一份校準結果文字。裝填手的音效開關同時控制原創合成的校準開始、一般／完美成功與失敗短音，靜音時仍保留所有視覺資訊。音效只讀快照的開始／結果邊緣，不決定判定或回血。

## 權威狀態與生命週期

`TankState.version = 3`，`repair` 與主炮 `weapon.jam` 分開：

- `status`：inactive、destroyed、stunned、crouching、moving、waiting、full、ready、repairing，表示當前工作原因。
- `blockedUntil`：共同遊戲時鐘上的最晚禁修期限；`failureUntil` 保留校準失敗期限，讓 HUD 正確說明較晚的等待原因。
- `activeSeconds`：實際有效維修的累積工作時間；滿血與受阻不推進。
- `calibration`：同一次的編號、結果、指針 elapsed、目標、下一次有效工作門檻、獨立隨機序列與全場暫停後的 suspended 狀態。隨機序列來自戰鬥 seed，不消耗或重設武器卡彈的隨機狀態。

`createRepairState`、`stepRepair`、`stopRepairCalibration` 與快照驗證位於 `web/tank-repair.ts`。規則起始值集中於 `REPAIR_RULES`。權威在離散輸入與動作之前先推進過去時間；正常放開 R 或蹲下會在隨後空白鍵獎勵前結算中斷。

缺員時 Runtime 先完成暫停前已經過的遊戲時間，呼叫明確的全場 `pause` 接點，再安全清除物理按鍵。HP、有效工作、指針、目標、受擊與失敗期限全部保留，不補算現實等待，不因房間自己的清除按鍵額外失敗。原職位重連後，活躍校準保持原位，裝填手重新按住 R 才續接；恢復後的移動、受擊或換工作仍是正常中斷。真正先送達房主的遊戲中放開／離焦與其後的房間暫停保留可靠有序通道的先後語意，不倒改已結算的正常中斷。

模式、維修與校準狀態跨波保留。回同房新開一局時由初始狀態重設 HP、工作進度、校準、獎懲及隨機序列。取消準備、換職、離開及返回依原有資源所有權失效與釋放，共用車內 renderer 不增加第二份 GPU 資源。

## 驗證接點

`tests/tank-repair.spec.ts` 與 `tests/tank-repair-lifecycle.spec.ts` 涵蓋第三模式、實際敵彈、三秒等待、2 HP／秒、100 上限、工作互斥、HP0 不復活及同房換職。

`tests/tank-repair-calibration.spec.ts` 從真實三人房間、正常敵彈、實際鍵盤、可見圓形／角度／HP／結果驗證校準。固定種子只替換既有戰鬥熵邊界；不注入 HP、位置、工作進度，不直接呼叫判定。一般／完美、工作中斷、完整兩秒漏按、退殼暈眩、受擊與失敗期限重疊、其他乘員缺員以及裝填手本人重連分開保留證據。實際通過的批次、來源版本、聲音擷取與人工聆聽限制由當次驗收報告記錄。
