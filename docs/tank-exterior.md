# 諾曼第外部場景

外部場景以 1944 年卡昂周邊的石造村落、農田與土路縮小重組，不宣稱重現某一場真實交戰。玩家使用 75mm M4A4／Sherman V，敵方分別為四號 H 型與虎式 I 型。指定基準的 Blender GLB 以不同車體斜面、炮塔、輪組、履帶、炮長及烘焙材質辨識型號；不是掃描模型或精密史實模擬。

`VehicleModel` 只負責呈現。既有外部場景繼續把權威位置與 yaw 轉換為 Three.js 的 -Z 前方，主炮 turret／elevation pivots 與獨立機槍視角仍讀共同快照。履帶依實際位移與轉向改變，不依動畫時鐘自行行駛；左右履帶在原地轉動時方向不同。敵車 phase 仍提供可見預警，擊毀後保留辨識得到的殘骸。權威 targets 不再包含的 ID 會同時移除對應模型與 GPU 資源，供後續波次替換使用。

可見石牆與村內農用建物填滿同一組 `BATTLEFIELD.cover` 實體範圍。建物的瓦頂留在石造女兒牆以內，不加沒有碰撞的屋簷；較遠的斜屋頂、樹木在可行駛邊界之外。低草與田間碎土不假裝成擋炮掩體。美術不修改車體碰撞、敵車尋路、傷害、時間或波次規則。

三個職位依 #30／#33 使用鋪滿頁面的真實視野與半透明角落 HUD，顯示方向、速度、HP 與當前工作，不再把戰場放在紙色工作站外框中。1280×720 與 1440×1050 保留可見準星及必要控制；遊戲仍需要桌機實體鍵盤。駕駛使用同一外景模組的固定車內眼位，透過實體裝甲隧道看前方；開口水平 60°、垂直 16°，不跟主炮轉動。裝甲內斜面、深度與局部工作光呈現厚度，沒有另改 Claude 的坦克／地景資產。車內裝填視角由獨立模組負責。

車輛 GLB 使用烘焙 2K atlas，地景使用 GLB、烘焙 atlas 與本機 1K 地面 PBR 色彩／OpenGL 法線／粗糙度貼圖，僅色彩使用 sRGB。漆面與裸鋼保留不同材質回應；方向日光、天空填光和 HDR 環境共同照明。來源、授權、原始與包裝後雜湊見 `public/art/README.md` 與 manifest；IWM 典藏只供型號與時代研究，沒有把版權圖片貼進遊戲。

車頂與第一人稱機槍使用同一套原創 Browning .50 幾何：機匣／頂蓋與鉸接、右側拉柄、鉚釘、供彈帶與彈箱、開口散熱支架、槍口、照門、兩側握把、蝶形扳機、U 形支架及腳座。第一人稱只由獨立機槍鏡頭帶動，不跟主炮轉；近景模型不投射虛假的巨大相機陰影。

每個 `VehicleModel` 獨占自己的幾何、材質與貼圖；同一 model 內部重複使用的資源只由 `dispose()` 單次釋放。波次刪除只釋放消失 ID 的 model，不釋放其他敵車或地景。沒有跨 model 借用資源的隱含全域快取。Sun shadow 只在實際車體／炮塔姿態或敵車集合變更時更新；靜止的畫面只保留低頻貼圖載入刷新，移動／瞄準／煙雲／飛行彈與命中效果照常呈現。權威模擬與網路的完整 elapsed 時鐘未被這個呈現快取限速或改寫；實際操作回歸及畫面驗收仍是效能退化的驗證界線。

準備按鈕會先顯示工作畫面準備中，等所選職位的真實貼圖、shader 編譯與首個 GPU draw 完成後，才發送既有準備票。裝填手同時預備車內與機槍，並重用同一組 renderer；取消、改職、離房或回大廳會取消過期準備並釋放所屬資源。駕駛同樣預備實際外景與裝甲視窗，開戰重用已準備的 canvas／renderer。

輸入整合層以單一 monotonic receipt cursor 先推進舊控制狀態，再套用新輸入／動作／連線狀態；不把先前 render 的完整 elapsed 反套到剛收到的新操作。暫停使用舊的 active／paused 邊界，恢復不補算暫停時間，較舊的 rAF timestamp 不會令 cursor 倒退。這是時間因果修正，不修改轉速推力、阻力、傷害或固定五秒暈眩。

## #27 歷史外觀驗收

使用者於 2026-11-07 明確更新：「接受目前簡化外觀，修正浮空零件後完成整合」。兩次先前的 `rebuild` 報告保留為歷史證據，不改稱原寫實標準已通過。該次保留簡化材質、田行與葉叢，並修正浮空扣件與燈具，獨立審查依當時明確接受的外觀給出 `ship`。#30 沿用後續指定的 `2e2a621` Blender 美術基準；本次圖像與資產層級須重新驗收，舊程序截圖與結論只供歷史背景。
