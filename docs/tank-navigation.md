# 共用戰場導航

戰鬥左下角的小地圖提供三名乘員相同的報路參考。駕駛、砲手及裝填手的裝填、機槍、維修模式都保留同一個導航元件。

北方固定朝上，東方在右。整張圖涵蓋可行駛場地的 84 × 84 公尺範圍，不隨相機或車身旋轉。田地及道路是新版地景的示意，來源為 `tools/blender/build_map.py` 的道路中心線與三塊田地；不呈現邊界外村落，也不作航照精度承諾。程序備援地景的道路形狀可能不同，固定掩體與可行駛邊界仍一致。

淺色箭頭代表己方位置與車頭方向，獨立細線代表主炮在戰場中的水平朝向。砲手轉動砲塔時細線轉動；駕駛轉動車身時，箭頭與細線都跟著轉，保留砲塔相對車身的角度。此圖不呈現主炮仰角或機槍方向，相關讀數仍在工作 HUD。

四處固定掩體使用 `web/tank-core.ts` 的 `BATTLEFIELD.cover`，與車體、砲彈碰撞及 3D 固定掩體共用資料。田地與道路只是參考，不新增碰撞或移動限制。己方位置及方向只讀每位乘員收到的同一份房主權威快照，不產生另一套模擬。

暖色方點代表隊伍目前觀測到的存活敵車。房主以駕駛真正的水平 60°／垂直 16° 裝甲前窗、砲手主炮及裝填手當前機槍外景統一判斷，反映姿態、俯仰、固定掩體與煙幕。裝填或維修車內不提供新發現，仍可讀取共享地圖。失去所有隊友視線立即移除即時標記；約五秒的最後已知位置保留／淡出由 #38 接入。

波次列的「目前觀測敵車」只計算共享情報中的存活敵車；主炮／機槍文字、血量、狀態及瞄準預告也只讀取同份觀測。沒有觀測時明示「目前沒有觀測到敵車」，不透露牆後或煙後的種類、血量、AI 階段或全場存活總數。己方受擊與戰鬥結果仍是全隊已知事件。

導航掛載在工作模式之外，換模式不會重建地圖或變更房間、工作進度及視野資源。新波次使用新敵車識別碼，舊標記會移除；新戰鬥清空情報。

實作接點：`tank-battle-view.ts` 共用實際外景眼位及投影；主炮／機槍保留垂直 65°，水平範圍由實際 canvas CSS 長寬比換算，畫質繪圖緩衝不改視野。客端透過既有有序、綁定乘員／epoch／sequence 的 held-input 通道回報有效正數比例，房主只判定其權威角色／模式；在第一次有效實際比例到達前不啟用該外景觀測。僅已掛載且尺寸大於零的外景回報；安全放鍵保留比例，新局清除權威比例並重新回報，暫停不更新情報。

`TankState.intel.contacts` 保存觀測時複製的位置、種類、血量、階段及遊戲時間，與敵車 AI 的 `lastSeenX/Z/At` 分開。視線使用敵車內縮輪廓取樣與既有權威盒狀掩體／3D 煙幕體積的近似；不做模型逐三角形判斷，也不改 AI 或傷害規則。3D 世界仍依既有快照渲染，正式情報不從完整世界物件讀值。
