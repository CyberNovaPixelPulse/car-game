# 共用戰場導航

戰鬥左下角的小地圖提供三名乘員相同的報路參考。駕駛、砲手及裝填手的裝填、機槍、維修模式都保留同一個導航元件。

北方固定朝上，東方在右。整張圖涵蓋可行駛場地的 84 × 84 公尺範圍，不隨相機或車身旋轉。田地及道路是新版地景的示意，來源為 `tools/blender/build_map.py` 的道路中心線與三塊田地；不呈現邊界外村落，也不作航照精度承諾。程序備援地景的道路形狀可能不同，固定掩體與可行駛邊界仍一致。

淺色箭頭代表己方位置與車頭方向，獨立細線代表主炮在戰場中的水平朝向。砲手轉動砲塔時細線轉動；駕駛轉動車身時，箭頭與細線都跟著轉，保留砲塔相對車身的角度。此圖不呈現主炮仰角或機槍方向，相關讀數仍在工作 HUD。

四處固定掩體使用 `web/tank-core.ts` 的 `BATTLEFIELD.cover`，與車體、砲彈碰撞及 3D 固定掩體共用資料。田地與道路只是參考，不新增碰撞或移動限制。己方位置及方向只讀每位乘員收到的同一份房主權威快照，不產生另一套模擬。

本票只提供己方導航，不讀取或顯示全場敵車。敵情的觀察、遮蔽及最後已知位置由後續 #37 接入。導航掛載在工作模式之外，換模式不會重建地圖或變更房間、工作進度及視野資源。
