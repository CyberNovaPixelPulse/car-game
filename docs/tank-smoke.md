# 煙霧彈與視線

裝填手的實體鍵 1／2／3 分別送出可靠離散動作 5／6／7，選擇高爆、穿甲與煙霧彈。三種彈共用原本的單發砲膛、開裝鎖定、卡彈、裝填模式限制、退殼、蹲下及五秒暈眩；煙霧不提供額外卸彈或補給規則。

煙霧彈是正常主炮投射物，依同一段掃掠碰撞命中敵車、固定掩體或地面。命中不扣任何敵我血量，只建立 `weapon.smoke` 的局部世界球域：命中 X/Z、地面上 2.5m 中心、5m 半徑、權威遊戲時鐘八秒截止。快照帶位置、範圍及截止時間；渲染、敵人視線和外部視角 HUD 使用同一組資料。暫停必須停止共同遊戲時鐘，不能用本機倒數消除煙霧。

煙幕是視線遮蔽物，沒有加入到車體或敵我投射物的實體碰撞名單。既有掩體仍會擋彈與擋車。高爆、穿甲、敵彈及機槍射線可以穿過煙，煙霧不燃燒也不持續傷害。

## 敵車行為

敵車快照保存 `lastSeenX`／`lastSeenZ`／`lastSeenAt`。只有目前視線不被煙和實體掩體遮住時更新最後已見點。初始未曾看見時的搜尋點是戰場進入點 (0,0)，時間 -100 表示沒有可供短暫盲射的新鮮記憶。

煙擋住視線時，瞄準及導航不再取玩家的目前位置，而是使用最後已見點。2.5 秒內可短暫繼續瞄準與射擊該點，之後進入 `searching`：掃動砲塔、朝舊點接近，停止發起新的射擊預告。已經開始的預告保留原本固定射線，按原截止時間真正發出砲彈；飛行中的砲彈仍正常前進。雲散或敵車真正重新看見玩家才恢復實時追蹤。沒有煙時保留原來固定掩體繞側的接近契約。

外部 HUD 只公開簡短的最後位置瞄準／搜尋活動。被煙遮住的敵車不再持續顯示即時血量、型別及射擊預告；沒有在 DOM 中輸出敵車或記憶點座標。駕駛依 #30／#31 從受限前窗觀察，煙幕仍是同一份世界遮蔽物。

## 後續波次整合

建立新的敵車時需初始化記憶三欄和既有全部敵車欄位。新敵車可以以地圖進入點作初始搜尋點，但不能把目前被煙遮住的玩家位置填入記憶。換波不重設煙幕、武器、裝填或卡彈，也不使用另一個敵人時鐘。`phase` 在原四種之外新增 `blind-fire` 與 `searching`。
