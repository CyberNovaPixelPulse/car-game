# 裝填手的兩種工作

Tab 切換車內裝填與車頂機槍。房主保存模式與兩套武器的方向、裝填進度、鎖彈、卡彈和熱度；切換不會重建武器。蹲下或暈眩時不能切換或工作。主炮的退殼風險在兩種模式完全相同。

機槍以按住 WASD 直接瞄準，放開立即停止，不使用主炮的離散慣性推力。空白鍵按住連射，每發對敵方靶標造成 1 點傷害，備彈無限。射線與掩體／靶標的盒體相交，只傷害最近的敵方靶標，不將己方坦克列為傷害對象。這些是遊戲化起始值，並非史實裝甲穿透模型。

連射約五秒升到滿熱，強制冷卻三秒；一般停火每秒降低 30% 熱度。切換模式、蹲下及暈眩不清除熱度或冷卻期限。冷卻依同一遊戲時鐘前進。機槍模式不能裝填、選彈或停卡彈指針；返回車內保留同一發的鎖彈和故障，仍需排除故障才能繼續。

MODE=8 沿可靠有序的離散 action 路徑；MG_FIRE=64 是持續 held bit。網路 held 驗證範圍刻意擴到 0..127，舊賽車仍只消費自己的按鍵位元。動作前先送目前 held 的因果契約維持不變，所以立即放 C 接 Tab 不會被過期蹲姿誤擋。

機槍畫面由真實 Three.js 第一人稱相機呈現，讀取獨立 yaw/pitch；示蹤線和靶標損傷皆讀房主快照。現階段場景與機槍程序幾何為功能階段，完整寫實二戰外觀及所有工作站的最終畫面由 #25/#26 完成。
