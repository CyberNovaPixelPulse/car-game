# 裝填工作區呈現

車內使用獨立 `TankInteriorScene`；它只收到既有 `TankState` 快照，建立封閉炮塔內壁、炮尾、後座導桿、下滑式滑塊、手輪、砲彈與彈架、地板與管線。沒有複製車外場景、敵人或掩體；駕駛仍不建立 3D renderer。裝填模式的隱私要求是「沒有外部戰場視野」，並不禁止真實車內 canvas。

砲彈沿裝填軸的位置直接讀 `weapon.loadProgress`，卡彈或放開 R 就停止。滑塊讀 `chamber`，退殼讀同一遊戲時鐘與 `ejectAt`；後座與飛出彈殼的動畫不改變砲膛、命中、傷害或時間。退殼完成後最多額外呈現 0.25 秒落下的彈殼，純粹是畫面餘韻，危險判定仍由原有 0.8 秒規則決定。靜止的空膛、裝好或暫停裝填畫面沿用已畫好的 canvas；視覺進度、退殼、姿勢、暈眩、尺寸、貼圖載入及返回裝填模式都會重新繪製。這只減少不變車內的重畫，權威時計與 HUD 仍繼續更新。蹲下降低車內相機；暈眩不遮黑畫面，保持恢復倒數可見，並在使用者偏好減少動態時停止暈眩鏡頭輕微傾斜。

機槍仍用獨立外部 `TankScene`。Tab 依權威 mode 循環裝填、機槍、維修；裝填與維修共用已準備的車內畫面，維修另有中央工作面板。隱藏的車內不繪製，外部 canvas 在回車內時移除但保留 renderer，避免每次重建。裝填、卡彈、彈種鎖定、熱度、維修回血與暈眩都不由 renderer 擁有。沒有手臂或人物模擬，不宣稱完整歷史操作還原。

短機械聲以 WebAudio 原創合成：滑動摩擦、閉鎖、退殼、卡彈、機槍點射及熱鎖分別由快照的階段變化觸發。沒有外部音樂、錄音或付費素材。按鍵或點擊才解鎖 AudioContext；音效開關同時控制機械聲、危險預警與命中聲，不影響權威工作限制。退殼警示、暈眩恢復、卡彈指針與熱度都有視覺提示。自動測試的預設 Chromium 靜音，測試通過不是人工聽驗證明。

史料定位依主規格 #11：1944 年諾曼第、75mm Sherman／M4A4 Sherman V；The Tank Museum 同頁的 Firefly 17 磅炮規格沒有拿來當本炮參數。幾何是原創近距離工作區呈現，不是博物館實車精確掃描。三人、盲開與退殼暈眩屬已確認遊戲規則。

材質的 diffuse、OpenGL normal、roughness 使用 Poly Haven 的 Rob Tuytel「Green Metal Rust」，授權 CC0-1.0。保留來源像素，只追加檔案內 origin metadata；`public/assets/interior/sources.json` 記錄精確來源、原始校驗值及 shipping 路徑。貼圖提供局部磨損與表面變化，不宣稱其為英軍歷史軍漆色號。沒有使用博物館照片或未授權模型。

## 當前視覺值

工作站沿用 PingFang TC / Noto Sans TC 系統字體、介面文字 `#e8e6dc` 與背景 `#252c2d`。裝填標題 18px、一般操作與下緣工作條 14px；退殼提示 18px／`#ffdf91`，暈眩倒數 `#ffcfb4`，場景暈眩內框 2px／`#c16d5c`。卡彈面板在場景前方正常排版，活動時縮短場景以保留指針、目標、倒數與工作進度；機槍外部視窗高度為 `max(300px, 100dvh - 340px)`。

車內背景 `#171e1c`，漆面基色 `#697367`／`#39473c`，裸鋼 `#81877f`，暗色機械 `#151b19`，彈殼 `#b8a06a`，橡膠 `#242925`。一盞柔邊工作聚光燈使用 1024 陰影，另有環境與局部補光；漆面 normal scale 0.22、裸鋼 0.07，貼圖重複 2×2。這是實作視覺值，並非歷史軍漆或工廠測量值。統一的外部及內部設計文件由最終美術整合階段彙整；本段保留此模組的實際來源值。
