# 戰鬥視覺特效

開火與爆炸的特效以戰車世界那種華麗、易讀的風格為目標，全部只讀取快照，不改變任何判定。快照時鐘暫停時，特效也會一起停住。

| 特效       | 觸發                    | 內容                                                                                                                                                                                                                                            |
| ---------- | ----------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 我方開火   | `shotsFired` 增加       | 白熱核心閃光、沿砲管噴出的火舌、左右側向的星形火焰、火藥火星、向前翻湧後上飄的砲口煙、砲口下方地面揚起的一圈塵土，加上短暫照亮周圍的閃光燈。                                                                                                    |
| 後座力     | 同上                    | 砲管後座約 0.42 m 再復進；車身車頭上抬、車尾下沉後經懸吊回彈（依砲塔方向分配成俯仰與側傾）；砲手視角最強烈的鏡頭後踢與震動，機槍位與駕駛依序較輕。                                                                                              |
| 敵方開火   | 敵車 `flashUntil` 更新  | 同一套砲口特效，四號戰車放大 1.15 倍、虎式 1.35 倍。                                                                                                                                                                                            |
| 砲彈曳光   | 飛行中的砲彈            | 我方為黃白色、敵方為橘紅色的發光拖尾。                                                                                                                                                                                                          |
| 高爆彈命中 | 新的 `impacts`（he）    | 刻意誇張：刺眼白光核心、兩道向外擴散的衝擊波光環、地面擴散光環、翻滾火球、往上衝並開成蕈狀雲的火柱與黑煙、14 道拖著火尾的燃燒碎片（像煙火）、泥土噴泉、碎石、地面塵圈、火星、強烈閃光燈，地上留下約 14 秒的焦黑痕跡；越靠近我車，鏡頭震得越大。 |
| 穿甲彈命中 | 新的 `impacts`（ap）    | 加大的白熱火星扇面、小型衝擊波光環、閃光與煙塵，近處會輕微震動鏡頭。                                                                                                                                                                            |
| 煙霧彈命中 | 新的 `impacts`（smoke） | 小閃光與白煙爆開（煙幕本體仍由原本的體積煙霧呈現）。                                                                                                                                                                                            |
| 擊毀敵車   | 敵車血量歸零            | 2.2 倍超大爆炸加 4 次殉爆；砲塔被炸飛到空中旋轉後歪斜摔回車體（遊戲風格的「砲塔飛天」），殘骸持續冒火和黑煙柱。                                                                                                                                 |
| 我車被擊中 | `lastHitAt` 更新        | 車身側面的火星與強烈鏡頭震動。                                                                                                                                                                                                                  |

粒子數量依畫質設定調整：低 1400、中 3200、高 5000 顆上限，生成密度分別為 0.5、1、1.4 倍。畫面中使用固定兩盞閃光燈，避免戰鬥中途新增光源導致所有材質重新編譯而卡頓。

實作：`web/tank-battle-effects.ts`，由 `web/tank-scene.ts` 每幀呼叫。

## 駕駛員觀察窗、外觀與車體機槍（第五輪）

- 駕駛員視窗改成二戰紀錄片中的直視觀察鏡：極暗的車內、窄長的髒污裝甲玻璃（污點、水痕、刮痕、兩端鍍鉻圓角反光），上下各一條稜鏡反射的模糊光帶，畫面整體偏冷灰、去飽和並加暗角。可見開口角度沿用 `DRIVER_VIEW`（偵察判定共用），只改呈現。實作：`web/tank-driver-armour.ts`、`web/tank.css`。
- 坦克外觀：`web/tank-weathering.ts` 以 shader 疊上戰場風化——履帶與下車體結塊泥巴、向上濺起的泥點、甲板與砲塔頂的落塵、側面雨痕與油污、細碎掉漆。每輛車隨機種子不同，烘焙貼圖仍共用。行進中的車輛會從車尾排出廢氣（加速時一口黑煙），速度夠快時履帶後方揚塵。
- 車體機槍（駕駛員按住空白鍵）：固定朝車頭方向射擊，有曳光彈、槍口焰、打到地面的塵土與打到坦克的跳彈火花；對坦克傷害極低（每發 0.05）。
