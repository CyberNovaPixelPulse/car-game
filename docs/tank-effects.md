# 戰鬥視覺特效

開火與爆炸的特效以戰車世界那種華麗、易讀的風格為目標，全部只讀取快照，不改變任何判定。快照時鐘暫停時，特效也會一起停住。

| 特效       | 觸發                    | 內容                                                                                                                                               |
| ---------- | ----------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| 我方開火   | `shotsFired` 增加       | 白熱核心閃光、沿砲管噴出的火舌、左右側向的星形火焰、火藥火星、向前翻湧後上飄的砲口煙、砲口下方地面揚起的一圈塵土，加上短暫照亮周圍的閃光燈。       |
| 後座力     | 同上                    | 砲管後座約 0.42 m 再復進；車身車頭上抬、車尾下沉後經懸吊回彈（依砲塔方向分配成俯仰與側傾）；砲手視角最強烈的鏡頭後踢與震動，機槍位與駕駛依序較輕。 |
| 敵方開火   | 敵車 `flashUntil` 更新  | 同一套砲口特效，四號戰車放大 1.15 倍、虎式 1.35 倍。                                                                                               |
| 砲彈曳光   | 飛行中的砲彈            | 我方為黃白色、敵方為橘紅色的發光拖尾。                                                                                                             |
| 高爆彈命中 | 新的 `impacts`（he）    | 白色閃光、滾動火球、高高噴起再落下的泥土、碎石、從彈坑升起的黑煙、地面衝擊塵圈、火星與閃光燈。                                                     |
| 穿甲彈命中 | 新的 `impacts`（ap）    | 白熱火星扇面、閃光與小股煙塵。                                                                                                                     |
| 煙霧彈命中 | 新的 `impacts`（smoke） | 小閃光與白煙爆開（煙幕本體仍由原本的體積煙霧呈現）。                                                                                               |
| 擊毀敵車   | 敵車血量歸零            | 1.6 倍大爆炸，接著 4 次彈藥殉爆，之後殘骸持續冒火和黑煙柱。                                                                                        |
| 我車被擊中 | `lastHitAt` 更新        | 車身側面的火星與強烈鏡頭震動。                                                                                                                     |

粒子數量依畫質設定調整：低 700、中 1800、高 3000 顆上限，生成密度分別為 0.5、1、1.4 倍。畫面中使用固定兩盞閃光燈，避免戰鬥中途新增光源導致所有材質重新編譯而卡頓。

實作：`web/tank-battle-effects.ts`，由 `web/tank-scene.ts` 每幀呼叫。
