# 三人坦克合作戰鬥

三位朋友以桌面瀏覽器與實體鍵盤，共駕同一台 Sherman，對抗三波四號 H 型與虎式 I 型敵車。各自維持語音通話：駕駛透過受限裝甲觀察窗看車頭前方，砲手看主炮戰場，裝填手切換裝填、車頂機槍與車內維修。

[開啟正式遊戲](https://car-game-necterelux.vercel.app/)

以下操作說明對應 #30 本機整合版本。本次視野、偵察與維修改版尚未部署；公開網址的 #27 歷史發布紀錄與本次驗收分列於 [最終驗證](docs/final-validation.md)。

## 本機啟動

使用 Node.js 22 以上，執行 `npm ci`，再於兩個終端分別執行 `npm run relay` 與 `npm run dev`。開啟 [本機遊戲](http://localhost:4273/)，建立房間並分享六碼代碼；三人各選一個職位，等待自己的準備完成，再由房主開始。需要 WebGL2，準備會載入素材、編譯 shader 並完成第一張畫面；準備失敗有可重試提示。

房主可以擔任任一職位；房主瀏覽器負責全部模擬。非房主斷線時戰鬥暫停，原乘員有現實 60 秒恢復；逾時回房重新選職準備。房主離開則結束房間。結算後任一人可讓全隊回到同一房間，換職再玩。

## 操作

- 駕駛：按住 W／S 前進／倒車，A／D 轉向；觀察窗隨車頭固定轉動，側後方由隊友協助報路。
- 砲手：按住方向鍵左右轉砲、上下俯仰，可同時操作；約半秒加速到最高轉速，放開約半秒停下，反向先煞停再反轉。車身轉向會帶動主炮世界朝向，轉砲不會改變車身。空白鍵在主炮裝好後開火。
- 裝填手：1 高爆、2 穿甲、3 煙霧；按住 R 裝填，放開保留進度，同發開始後鎖定彈種。卡彈時按空白鍵把指針停在目標區，失敗等一秒再試。
- 裝填手按住 C 蹲下，避開約 0.8 秒後退出的彈殼；蹲下不能工作。站著被彈殼擊中會固定暈眩五秒。
- Tab 循環裝填→機槍→維修→裝填。機槍按住 WASD 瞄準，空白鍵連射；持續五秒過熱，強制冷卻三秒。切模式不能跳過危險、卡彈或冷卻。
- 維修：停車並停止轉向後，按住 R 每秒回復 2 HP，無耗材、上限 100；受敵彈傷害後等三秒，重複命中重新計時。放開 R、移動、轉向、蹲下、暈眩或切工作即停止。血量歸零無法復活。實際工作 3～6 秒出現兩秒一圈的校準，空白鍵一般／完美額外 +1／+3 HP；按錯、漏按或校準中斷停修兩秒，與受擊等待取較晚者。缺員暫停保留指針，重連後重新按 R 續接。
- 共用導航：三名乘員與裝填、機槍、維修三種工作都可看見同一份小地圖。北方固定朝上，箭頭是車頭，獨立細線是主炮；車身轉動會同時帶動兩者，砲手轉砲只改變細線。

導航顯示整個 84 × 84 公尺可行駛場地。田地與道路是依目前新版地景繪製的示意，石牆及建物位置與實際固定掩體一致；地圖不隨鏡頭旋轉。暖色方點與文字敵情只顯示隊友透過駕駛前窗、主炮或當前機槍外景實際觀測的敵車；固定掩體、煙幕、視角及俯仰會限制發現，車內裝填／維修只讀共享情報。

實心方點是目前觀測，空心方點是最後已知。失去視線後位置與已知血量停止更新，舊情報約五秒遊戲時間淡出；文字標示觀察年齡，舊射擊階段不繼續當成當前警報。再次看到敵車會刷新情報，換波及新局清除舊標記。缺員暫停時點位、透明度與年齡都凍結，重連後續接。

高爆可波及鄰近敵車；穿甲對單車傷害較高；煙幕遮住敵我視線，但不擋砲彈、機槍或車體。固定石牆與建物擋車擋砲，敵車會繞側。關鍵危險都有可見提示，裝填手可切換音效。

## 開發與建置

`npm run check` 檢查型別，`npm run build` 產生可部署的 `dist/`，`npm test` 執行型別與驗證政策檢查、收集端到端案例，預設不開瀏覽器。E2E須經 `npm run test:e2e -- ...` 並符合 [專案執行草案](docs/agents/execution-plan.md) 的主機與時間限制。沒有 C、SDL2、Python 或 Emscripten 建置依賴。只使用根目錄入口，舊賽車及 Wasm 已移除。建置不會部署。

可用 `WEB_PORT`、`PEER_PORT` 設定測試服務埠；開發前端的 relay 使用 `VITE_PEER_HOST/PORT/PATH/SECURE`（見 [.env.example](.env.example)）。正式靜態建置未設定自架 relay 時使用 PeerJS Cloud，實際連線仍受 NAT／網路環境影響。正式網站已於 2026-11-07 更新為坦克版本，並以三個獨立瀏覽器在公開網址完成入房、準備、開戰、裝填、卡彈排除、射擊、退殼與機槍視角驗證；不需本機連線服務。

本機完整 Chromium 可明確選用 `TANK_NATIVE_BROWSER=1 npm test`；它啟用完整 Chromium、保留 sandbox 並移除預設 unsafe SwiftShader，沒有放寬瀏覽器安全性。預設仍使用 Playwright 標準設定。這是測試環境選項，不是 FPS 保證。詳細驗證、三獨立瀏覽器及證據指令見 [測試說明](docs/testing.md)。

本版保留指定基準的 Blender 坦克與諾曼第地景 GLB、烘焙材質和原創車內；素材出處與雜湊見 [素材來源](public/art/README.md)、[車內來源](public/assets/interior/sources.json)。#27 曾接受的簡化外觀是歷史驗收範圍，本次沒有重建美術或重新承諾原寫實標準。設計見 [DESIGN.md](DESIGN.md)，規則起始值見 [平衡設定](docs/tank-balance.md)。

戰鬥採全頁場景與角落 HUD；每名乘員可自行以右上按鈕進出瀏覽器全螢幕，Esc 返回視窗後繼續操作。瀏覽器不開放全螢幕時仍可使用全頁畫面。大廳維持手冊風格；HUD／工作面與顯示控制見 [戰鬥頁面](docs/tank-hud.md)。
